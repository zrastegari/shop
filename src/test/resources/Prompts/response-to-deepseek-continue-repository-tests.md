عالیه، همه چیز سبزه. بریم سراغ Repository tests.

یادآوری از فاز ۱ (که قبلاً باهاش مشکل شبکه داشتیم و حلش کردیم): برای
`ActiveSharedTripRepositoryTest` / `WaitingPassengerRepositoryTest` /
`SharedTaxiOfferRepositoryTest` (هر کدوم که لازمه)، از همون الگوی فاز ۱ استفاده کن:

- **اتصال مستقیم به MongoDB لوکال واقعی** (`localhost:27017`)، نه Flapdoodle
  embedded Mongo (که به‌خاطر محدودیت شبکه قبلاً fastdl.mongodb.org رو نمی‌تونست
  دانلود کنه)
- از یک دیتابیس/پروفایل تست جدا استفاده کن (مثلاً `carpooldb_test` که قبلاً ساخته
  شده بود رو می‌شه استفاده کرد، یا یک دیتابیس تست جدید مثل `sharedtaxidb_test` — هر
  کدوم راحت‌تره)
- با `@AfterEach { deleteAll() }` مطمئن شو تست‌ها مستقل و داده‌ها بین اجراها پاک
  می‌شن

بعد از این‌که Repository tests هم سبز شدن، لطفاً یک خلاصه‌ی کامل از کل فاز ۲ (فایل‌ها،
تعداد تست‌ها، تصمیمات کلیدی مثل مدل B) بده — دقیقاً مثل گزارشی که برای فاز ۱ گرفتیم —
تا بتونم وضعیت پروژه رو آپدیت کنم.
